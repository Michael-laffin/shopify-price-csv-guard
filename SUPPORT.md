# Feedback and bug reports

Use https://github.com/Michael-laffin/shopify-price-csv-guard/issues for non-confidential feedback once the public repository is available. No support response, availability or response time is promised.

Do not upload or attach CSV exports, customer data, store data, personal information, credentials or sensitive values. Describe the problem using synthetic examples only. GitHub Issues are public; do not post private information there. This demo does not request or receive merchant files.
