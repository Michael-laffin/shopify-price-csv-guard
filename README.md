# Price CSV Guard — standalone fictional demo

This exact page has been verified in desktop Google Chrome when served over local HTTP. Direct `file://` opening and completely offline execution have not been verified. For the tested launch path, serve this folder with an existing Python installation: `python -m http.server 8769 --bind 127.0.0.1`, then open `http://127.0.0.1:8769/`. No account or CSV upload is required. Do not install software or expose the server to your network merely to try this demo. The two buttons run synthetic fictional examples in the browser: price-only shows two price changes and no blocking findings; blocked barcode shows a fictional change to spreadsheet scientific notation. “proposed-safe” is a price-only fixture name, not import approval. You may instead choose two local UTF-8 product CSV files and compare, the shipped examples contain fictional data only. No Shopify store connection or import is performed.

This is a read-only comparison aid, not Shopify import approval, a commercial price recommendation, or a paid offer. The app uses the File API to process selected bytes within the current browser tab, with no analytics, storage, network API, or file upload. A hosted page itself makes an ordinary request to its host, which may log visit metadata. The optional downloaded JSON may contain selected field values; it remains on your device until you remove it. Clear or reload discards app-held files and results, not downloads, and is not secure erasure.

## Strict limits

Each input is limited to 2 MiB (2,097,152 bytes), 10,000 data records, and 256 columns. Fatal invalid UTF-8, malformed CSV, invalid decimal prices, unsupported headers and ambiguous rows fail closed with no partial report. Required exact headers: `URL handle`, `Option1 name`, `Option1 value`, `Price`, `SKU`, `Barcodes`. `Compare-at price` is optional, and Option2/Option3 names and values must occur in pairs. Headers, row order, identities and all non-price decoded values must remain unchanged. Only Price and Compare-at price may change; Price uses unsigned decimal with 1–12 integer digits and at most two decimal digits (Compare-at may be blank). Structural and non-price changes block review. Blocked structural comparisons do not confirm variant matches; any price changes shown are positional.

JSON retains every structural and identity finding within the input limits, but limits other findings and price changes to 1,000 details each and reports omission counts. The screen independently previews at most 1,000 of each. Counts include all detections. No report approves an import or checks the destination store. The app does not produce import, restore, or rollback files.
